# Sealion

Sealion Home과 Sealion Link의 공개 다운로드 사이트입니다.

소개와 다운로드: https://rimin-launcher.github.io/

이 저장소의 웹사이트 부분(`site/`)은 공개 APK와 서명된 업데이트 정보만 게시합니다. 서명 키는 포함하지 않습니다.
main에 올린 파일은 검사 후 GitHub Pages로 게시됩니다.

`vehicle-launcher/`에는 통합 런처(Sealion One)와 휴대폰 키 앱(Sealion One Key)의 소스가 있습니다. 웹사이트에는 게시되지 않으며, 자세한 내용은 [vehicle-launcher/README.md](vehicle-launcher/README.md)를 참고하세요.
