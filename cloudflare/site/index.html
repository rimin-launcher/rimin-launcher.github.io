Features

무엇을 할 수 있나요?

자주 쓰는 기능을 꺼내 쓰기 쉽게 모았어요. 지원 범위는 차량 펌웨어와 권한에 따라 달라요.

LUMI HOME

자주 쓰는 기능을 홈 화면에서

  • 내비게이션과 앱자주 쓰는 내비 앱과 차량 메뉴를 홈에서 바로 열어요. 내비 화면을 계기판에 띄울 수도 있어요.
  • Bluetooth 음악차량이 보내 주는 재생 정보와 연결된 휴대폰의 음악을 보여 줘요.
  • 나에게 맞는 화면화면 방향과 구성을 바꾸고, 기본 홈으로 설정해요. 기본 홈 변경은 차량이 허용해야 해요.
LUMI HOME

온도와 시트를 한곳에서

  • 온도와 바람운전석·동승석 온도, 풍량, 바람 방향을 조절해요.
  • 열선과 통풍시트 열선·통풍과 핸들 열선을 공조 화면에서 바로 찾아요.
  • 공조 설정AUTO, A/C, 내기 순환, 유리 김서림 제거처럼 차량이 지원하는 기능을 모았어요.
LUMI HOME + LINK

주변 보기와 영상 저장

  • 카메라 보기지원되는 카메라를 연결해 화면과 채널을 맞추고, 화면을 끌어서 각도를 조절해요.
  • 녹화와 저장 영상블랙박스·주차 녹화를 설정하고 저장된 영상을 확인해요.
  • 휴대폰에서 확인차량 전원과 네트워크, 카메라 권한이 필요해요. 시동이 꺼진 상태의 녹화는 아직 보장하지 않아요.

LUMI LINK + WATCH

휴대폰과 손목에서 내 차를

  • 다가가면 열리고, 멀어지면 잠겨요등록한 차량 Bluetooth 신호와 걸음 감지로 접근과 이탈을 판단해요. 활동·Bluetooth 권한이 필요해요.
  • 원격 제어와 새로고침문 잠금, 트렁크, 냉난방을 원격으로 조작하고, 홈 화면을 아래로 당기면 차 상태를 새로 불러와요.
  • 설정은 그대로앱을 지우지 않고 업데이트하면 계정과 자동 잠금 설정이 유지돼요.

위 화면 그림은 설명을 위한 예시예요. 실제 앱 화면과 다르고, 표시된 숫자도 예시입니다.

Get ready

설치는 세 단계면 끝나요.

설치할 기기를 고르고 순서대로 따라 하세요.

파일 받기

Lumi Home APK를 내려받아 USB나 차량에서 열 수 있는 곳으로 옮기세요.

설치 허용하고 실행

차량 파일 관리자에서 APK를 열고, 안내에 따라 설치 권한을 허용하세요.

연결 확인

처음 실행하면 연결 안내가 열려요. 권한과 연결 상태를 확인하고 기본 홈으로 선택하세요.

파일 받기

Android 휴대폰에서 Lumi Link APK를 내려받으세요. iPhone용 앱은 없어요.

설치 승인

받은 파일을 열고 브라우저나 파일 관리자의 ‘알 수 없는 앱 설치’를 허용하세요.

내 차 등록

BYD 계정을 연결해 차량을 등록하고, 활동·Bluetooth·근처 기기 권한과 백그라운드 실행을 허용하세요.

휴대폰에 Lumi Link 준비

워치는 휴대폰의 Lumi Link를 통해 차와 연결돼요. 먼저 휴대폰 설치를 마쳐 주세요.

워치에 APK 보내기

워치 설정 → 개발자 옵션에서 무선 디버깅을 켜고, 휴대폰의 설치 도우미 앱으로 Lumi Watch APK를 워치에 설치하세요.

워치 연결

휴대폰 Lumi Link의 ‘갤럭시워치’ 화면을 열고 안내에 따라 워치를 연결하세요.

↻

그다음 업데이트는 앱이 알려 줘요.

차량과 휴대폰 앱은 실행할 때 새 버전을 확인하고, 파일 서명까지 검사한 뒤 Android 설치 화면으로 안내해요. 설정을 지키려면 앱을 지우지 말고 업데이트하세요.

Before you start

자주 묻는 질문

어떤 차량과 휴대폰에서 쓸 수 있나요?

SEALION 7의 Android 차량 디스플레이를 기준으로 만들고 있어요. 최소 Android 11이 필요하고, 차량 펌웨어와 권한에 따라 쓸 수 있는 기능이 달라요. Lumi Link는 Android 휴대폰 전용이에요.

순정 런처 대신 기본 홈으로 쓸 수 있나요?

차량이 기본 홈 앱 변경을 허용해야 해요. 설정에서 기본 런처 설정·유지를 시도할 수 있지만, 차량 펌웨어 정책에 따라 적용되지 않을 수 있어요.

시동이 꺼져 있어도 카메라·주차 녹화가 되나요?

카메라와 본체 전원, 네트워크가 유지되고 차량이 관련 권한을 줘야 해요. 지금은 시동이 꺼진 상태의 녹화와 원격 영상을 보장하지 않아요.

주차 센서 거리와 앞차 출발 알림은요?

차량이 거리 값과 출발 신호를 보내 줘야 해요. 신호가 들어오지 않으면 거리나 알림을 임의로 만들어 보여 주지 않아요.

Sealion Home·Link를 쓰고 있었어요. 어떻게 되나요?

이름만 Lumi로 바뀐 같은 앱이에요. 앱의 업데이트 안내에 따라 설치하면 Lumi Home·Lumi Link로 바뀌고, 계정·차량 등록·연결·자동 잠금 설정이 그대로 유지돼요. 그다음 업데이트는 이 사이트(lumi-launcher.dev)에서 받아요.

업데이트하면 설정이 유지되나요?

같은 앱을 지우지 않고 업데이트하면 유지돼요. 앱을 지우거나 앱 데이터를 삭제하면 다시 설정해야 해요.

회원가입이 필요하거나 내 정보를 수집하나요?

다운로드에는 회원가입이 필요 없어요. 이 사이트에는 광고나 방문 분석 스크립트가 없어요. 차량 계정이 필요한 기능은 앱 안에서 따로 연결해요. 자세한 내용은 개인정보 안내를 확인하세요.
